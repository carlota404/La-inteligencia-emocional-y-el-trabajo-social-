# La-inteligencia-emocional-y-el-trabajo-social-
Este trabajo explora el papel esencial de la Inteligencia Emocional (IE) en el Trabajo Social, analizando cómo la autorregulación profesional optimizan la intervención en situaciones de alta vulnerabilidad. El estudio demuestra que una adecuada gestión emocional no solo fortalece el vínculo de confianza con el usuario y mejora la resoluciones
